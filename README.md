# 嘉庚智慧馆员 · AI 智能馆员 Agent

> 厦门大学嘉庚学院图书馆 · 第二届 AI 应用创新大赛参赛作品
> 用一句话，找到 45 万册藏书中最懂你的那一本

## 它能做什么

| 能力 | 大白话示例 |
|---|---|
| 自然语言查书 | 「有没有讲经济法的入门书？在几楼？」→ 给楼层、索书号、入门推荐 |
| 自习人流预测 | 「现在图书馆人多吗？几点去合适？」→ 基于真实门禁+座位数据 |
| 顶刊文献找书 | 「Nature 最近脑机接口有什么热点？馆里有配套书吗？」 |
| 个性化荐书 | 结合你的借阅历史 + 本周微博/抖音热搜，推接得上你口味的书 |
| 阅读画像报告 | 输入学号，生成年度借阅画像（像网易云年度歌单那种） |
| 馆务咨询 | 开放时间、节假日安排——不知道就明说，绝不瞎编 |

## 技术亮点

- **不是聊天机器人，是 Agent**：DeepSeek Function Calling，大模型自己调用 30 个数据工具取真实数据
- **防幻觉**：所有书名、索书号、数字都来自图书馆真实数据，无数据就明说
- **推荐算法**：协同过滤（看过去）+ 零借阅挖掘（看将来），回应「像抖音一样懂人」
- **真实数据**：45.3 万册馆藏 / 3.7 万条借阅 / 379 万人次入馆 / 4.9 万条座位 / 4 万篇论文
- **轻量部署**：Python Flask + pandas，双击 `一键启动.bat` 即可运行

## 快速开始

### Windows（推荐）
1. 安装 Python 3.10+（勾选 Add to PATH）
2. 把 `demo/` 和 `extracted/` 放在同一目录
3. 把 `demo/config.example.json` 复制为 `config.json`，填入你的 DeepSeek API Key
4. 双击 `一键启动.bat`
5. 浏览器打开 http://127.0.0.1:8000

### 手动启动
```bash
cd demo
pip install -r requirements.txt
python app.py
```

## 项目结构

```
├── demo/
│   ├── app.py              # Flask 服务入口
│   ├── library_engine.py   # 数据引擎 + Agent 逻辑
│   ├── index.html          # 前端三栏页面
│   ├── hot_topics.json     # 本周热点
│   ├── hot_papers.json     # 顶刊热点
│   ├── config.example.json # 配置模板（复制为 config.json 填 Key）
│   └── requirements.txt
├── extracted/              # 图书馆开放数据（需自备）
└── 一键启动.bat
```

## 伦理承诺

- **隐私**：学号仅查本人借阅，不留存对话与画像明细
- **防幻觉**：事实性回答必须来自真实数据，无数据时明确告知
- **算法公平**：推荐兼顾热门与冷门，设零借阅保底曝光位
